# 眼科会议速查 · 微信小程序

《医学进行时》眼科会议速查的小程序版。会议数据和网页版（仓库根目录 `index.html`）共用同一份，功能与网页版一致，并补上两项微信内网页做不到的能力：

- **写入手机日历**：用小程序原生接口写入系统日历，开幕前 7 天、每个投稿/注册截止前 3 天提醒。网页版在微信里无法下载日历文件。
- **转发会议卡片**：详情页可直接转发给好友/群，也可分享到朋友圈；对方点开直接进入该会议详情。

## 功能

| 页面 | 内容 |
|---|---|
| 首页 | 下一场重点国际会议倒计时；30 天内截止节点；搜索；筛选（即将召开 / 📮 截止节点 / ☆ 我的收藏 / 全部 / ⭐ 重点 / 国内会议）；亚专业方向筛选；下拉刷新 |
| 会议详情 | 时间地点、方向标签、待到节点、投稿与注册说明、注册费表；收藏、加入日历、复制信息、转发；复制官网链接（无官网的复制检索词：国内会议用微信搜一搜，国际会议用谷歌） |

小程序不能直接打开外部网页（官网），所以官网按钮做成「复制链接」，提示用户到浏览器打开。

## 更新会议数据

只维护一份数据：改根目录 `index.html` 里的 `CONFS`，然后在仓库根目录运行

```bash
node scripts/build-mp-data.js
```

会重新生成 `miniprogram/data/confs.js`。数据打包在小程序里，**每次更新数据都要重新上传并提交审核**（小改动一般几小时到 1–2 天）。如果以后更新频繁，可以把数据挪到微信云开发，改数据不用再过审，届时再改造。

## 上线步骤

### 1. 注册小程序

- **推荐**：公众号「医学进行时」如果是已认证的企业/个体户主体，在公众号后台 →「小程序管理」→「快速注册并认证小程序」。复用公众号资质，免 300 元认证费，注册后自动与公众号关联。
- 否则在 mp.weixin.qq.com 用一个未注册过微信产品的邮箱注册。个人主体注册免费，但类目和接口受限。

### 2. 填写基本信息

- 名称建议：「眼科会议速查」（名称需唯一，被占用就加前缀如「医学进行时会议速查」）
- 简介：国内外眼科与视光学术会议时间、地点、投稿与注册截止查询
- **服务类目选「工具 > 信息查询」**。不要选医疗类目，那需要医疗机构资质

### 3. 备案

后台「设置 → 基本设置 → 小程序备案」在线提交。未备案不能上线，通常要一到几周，**注册后第一时间提交**。

### 4. 填写用户隐私保护指引

后台「设置 → 服务内容声明 → 用户隐私保护指引」，声明本小程序用到的两项：

- **剪切板**：用于复制会议信息、官网链接
- **日历**：用于把会议和截止节点写入手机日历

不声明的话这两个功能在线上会被拦截。小程序不收集任何用户信息，收藏只存在用户手机本地。

### 5. 用开发者工具打开并上传

1. 下载安装「微信开发者工具」（稳定版）
2. 导入项目，目录选本仓库的 `miniprogram` 文件夹，AppID 填后台「开发管理 → 开发设置」里的 AppID（会写回 `project.config.json`）
3. 模拟器里检查无误后，点「预览」用手机扫码真机试用，日历功能必须真机测试
4. 点「上传」，版本号如 `1.0.0`

### 6. 提交审核并发布

后台「版本管理」→ 把上传的开发版设为体验版自测 → 提交审核（一般 1–7 天）→ 通过后点「发布」。

### 7. 在公众号里推广

- 公众号后台「小程序管理」关联该小程序（快速注册的已自动关联）
- 自定义菜单加「会议速查」，跳转小程序
- 文章里插入小程序卡片或小程序码

## 第二期可以加的

- **订阅截止提醒**：读者在会议详情点「提醒我」，截止前收到微信服务通知。需要云开发存订阅记录并定时推送，会产生少量月费
- **数据云端化**：会议数据放云开发数据库，改数据即时生效、不用过审
