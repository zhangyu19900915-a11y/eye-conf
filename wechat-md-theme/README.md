# doocs/md 公众号主题（医学进行时 / 视光进行时）

这些主题用于在 [doocs/md](https://md.doocs.org)（开源微信 Markdown 编辑器）里用 Markdown 写稿，然后一键复制到公众号后台。样式规格对齐 med-wechat-publishing §5：

- 正文 15px、黑色，行高 1.8；
- 字号上限 15px，标题层级靠颜色、竖线和色块区分；
- 不使用 flex、渐变和两端对齐。

适用场景：短讯、通知、会议预告、简单解读等不需要复杂组件的稿件。药企项目稿和需要时间轴、对比双栏、纯 CSS 条形图的稿件，仍按原流程走：Word 确认 → `wechat-template.html`。

## 一次性设置（约 2 分钟）

1. 打开 https://md.doocs.org。
2. 在顶部「样式」中设置：
   - 主题选「经典」；
   - 字号选 15px；
   - 「两端对齐」保持关闭；
   - 图注格式按需选择，推荐「只显示 alt」。
3. 打开「样式 → 自定义 CSS」，新建方案，把 `themes/` 下对应文件的全部内容粘贴进去：
   - `01-蓝金-医学进行时.css`
   - `02-墨绿金-综述基础.css`
   - `03-深紫银-神经眼科基因.css`
   - `04-青灰橙-视光进行时.css`

   四套可以分别存成四个方案，切换公众号或栏目时直接切方案。
4. 自定义 CSS 保存在浏览器本地。换电脑或清缓存后，需要重新粘贴一次。

## Markdown 写法 → 排版组件

| 写法 | 效果（对应 skill §5 组件） |
|---|---|
| `# 标题` | 主标题：15px，加粗，主色 |
| `## 标题` | 一级标题：左侧点缀色竖线 |
| `### 标题` | 二级标题 A：点缀色下划线 |
| `#### 标题` | 二级标题 B：强调色实心色块（白字 14px），与 `###` 交替使用 |
| `##### 标题` | 灰色辅助小标题 |
| `> 文字` | 导语/总揽框：浅主色底 + 点缀色左竖线 |
| `> [!IMPORTANT] 研究速览` | 研究速览卡：主色描边 + 主色标题条 |
| `> [!TIP] 临床意义` | 临床意义/要点框：米金底 + 金边 |
| `> [!NOTE] 专家点评` | 专家点评框：浅底 + 强调色竖线 |
| `> [!WARNING] 合规提示` | 灰色提示条，用于写「该适应证国内尚未获批」 |
| `> [!QUOTE] 参考文献：` | 参考文献区块：13px 灰色 |
| `==+6.7 个字母==` | 关键数据：点缀色加粗 |
| `**文字**` | 黑色加粗 |
| 表格 | 主色表头，14px |
| `![图 1 …](图片链接)` | 图片居中，图注 12px 灰色 |

提示块 `[!XXX]` 后面同一行的文字就是框标题，可以按需改写，例如 `> [!TIP] 要点速览`。完整示例见 `示例稿.md`：把它粘进编辑器，就能看到所有组件的效果。

## 不开网页：命令行直接出微信 HTML（md2wechat.mjs）

这条路径和网页版「复制」用的是同一套管线：doocs/md 渲染器渲染，叠加本目录主题，再用 juice 把样式内联。之后脚本会清掉 `<style>`、class、CSS 变量和 `color-mix()`，给块元素补上显式对齐，按 med-wechat-publishing §5 自检，最后输出带「复制正文」按钮的成品 .html。

一次性安装需要 Node.js 22.22.2 或更高版本：

```bash
git clone https://github.com/doocs/md.git ~/doocs-md
cd ~/doocs-md && corepack enable && pnpm install   # 国内用默认镜像即可
cd <本仓库>/wechat-md-theme && npm install          # 安装 juice
```

每次出稿：

```bash
MD_REPO=~/doocs-md node md2wechat.mjs 稿件.md themes/01-蓝金-医学进行时.css 稿件.wechat.html
```

- 第二个参数是主题，省略时默认用蓝金。
- 第三个参数是输出路径，省略时输出为 `稿件.wechat.html`。
- 自检发现 flex、渐变、两端对齐、`text-align:start` 或 CSS 变量残留时，脚本会报错，退出码为 1。
- 用浏览器打开生成的 .html，点「复制正文」，再粘贴到公众号编辑器即可。

## 修改与重新生成

所有配色都在 `build.mjs` 顶部的 `themes` 数组里。改完后运行：

```bash
node wechat-md-theme/build.mjs
```

脚本会重新生成 `themes/*.css`。如果输出里含有 flex、渐变或 justify，脚本会直接报错退出。

## 已知限制

- 微信「内容结构检测」对 `text-align` 的要求，本主题已为所有块元素写明 `text-align:left` 或 `center`。但 doocs/md 复制时由编辑器自己内联样式，首次使用请先在公众号后台预览一次，确认没有对齐告警。
- 时间轴、对比双栏、条形图、问答卡等复杂组件，Markdown 无法表达，仍需用 skill 的 HTML 模板制作。
